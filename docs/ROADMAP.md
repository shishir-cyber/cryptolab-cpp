# Roadmap

Each phase ends with a tagged release.

- [x] **Phase 0**: repo, CMake, CI, tests, formatting, sanitizers (`v0.0.1`)
- [ ] **Phase 1**: classical ciphers + matching cryptanalysis (`v0.1-classical`)
- [ ] **Phase 2**: DES/3-DES/AES, modes of operation, NIST vectors (`v0.2-block-ciphers`)
- [ ] **Phase 3**: big integers, number theory, RSA/ElGamal/DH, primality tests (`v0.3-public-key`)
- [ ] **Phase 4**: hashes, signatures, Shamir secret sharing (`v0.4-hash-sig`)
- [ ] **Phase 5**: attack lab: differential/linear, TMTO, padding oracle (`v0.5-attacks`)
- [ ] **Phase 6**: hybrid PQ messenger (libsodium + liboqs) (`v0.6-secure-msg`)
- [ ] **Phase 7**: docs, benchmarks, threat model, demo (`v1.0`)
